The pad is a 2-D exploration map. Click anywhere to generate a clip at that coordinate; each click leaves a dot you can audition and insert.

Pad axes

X · simple ↔ complex
Rewrites your prompt before sending it. Left prepends qualifiers like minimal, sparse; right appends layered, polyrhythmic, dense arrangement. The dead-center 6% sends the prompt verbatim so you can A/B against the modifiers.
Y · chaotic ↔ strict
Sweeps the engine's "creativity" knob. Top of pad = looser, more surprising; bottom = tighter, more faithful to the prompt.
temperature
Magenta only. Top of pad = 1.6 (chaotic), bottom = 0.5 (strict). Higher temperature widens the sampling distribution, so the model picks rarer continuations.
cfg_scale
Stable Audio 3 only. Top of pad = 0.5 (creative), bottom = 5.0 (strict). How hard the diffusion process is "pushed" toward your prompt — higher = obeys the text more literally but can sound rigid.

Stable Audio 3 controls

diffusion steps
How many denoising passes the model runs. More steps = cleaner, more detailed audio but slower. 30–50 is fast preview quality; 80–120 is final-render quality.
duration
Length of the generated clip in seconds. Longer = slower (linear cost).
Condition on selected clip
When you right-click an arrangement selection, the extension renders that region to a WAV. This toggle hands the WAV to SA3 as init_audio — the model uses your clip as the noisy starting point of the diffusion. The output stays in your clip's harmonic and timbral world while honoring the prompt. Default: ON whenever a clip was rendered.
noise level
Only meaningful when Condition on selected clip is on. Low (0.05–0.4): barely changes your clip — small variations. Mid (0.5–0.8): keeps the vibe but lets the prompt drive new ideas. High (0.9–1.0): source clip is just a hint; SA3 is mostly text-driven. Defaults to 0.8 (matches Stable Audio 3's upstream default).

Buttons & gestures

AI x4
Drops one dot at the centre of each quadrant (simple+chaotic, complex+chaotic, simple+strict, complex+strict) and runs them in sequence. One-click survey of the prompt's space.
Shift-click dot
Adds the dot to a multi-select batch (teal ring). Click Insert N selected to splice all of them in as separate new audio tracks.
Insert into New Track
Creates a fresh audio track in Live next to the source and drops the previewed clip on it. Your original track is never overwritten.
Reset State
Magenta only. Clears the model's autoregressive memory between takes. Use it when generations start drifting toward the same loop.
Clear Map
Removes every dot from the pad and forgets the multi-select batch.
Pin seed
Switches the model into deterministic mode. With the pin on, the same prompt + same pad coordinate + same seed reproduces the same audio every run — useful for demos. The dice button rolls a fresh random seed. AI x4 uses seed, seed+1, seed+2, seed+3 when pinned, so the four quadrants stay distinct but reproducible together. Each finished dot's tooltip shows the seed it was generated with.

Project context (Stable Audio 3)

The chips above the pad show your Live set's BPM and key (read from Song.tempo / Song.rootNote / Song.scaleName). For SA3, those values are auto-appended to the prompt as "…, 120 BPM, in C Minor; do not change tempo or key". Hover any finished dot to see the exact prompt that was sent.
